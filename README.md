# Matsvep

Privat veckomeny-app: veckobudget, svep recept, sammanslagen inköpslista och priser för butikerna nära Värnhem i Malmö.

- Appen: `index.html` (GitHub Pages)
- Data: `data/data.json`, uppdateras varje natt av `.github/workflows/update.yml`
- Recept hämtas från ICA, Lidl, Linas Matkasse, Coop och Willys. Bilder och recepttexter tillhör respektive sajt och visas med länk till originalet. Endast för privat bruk.
